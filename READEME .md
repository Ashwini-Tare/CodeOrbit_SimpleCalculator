# Simple Calculator

## Project Description
This is a simple calculator built using Python. It performs basic arithmetic operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Error handling for division by zero
- Handling invalid input

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `python Simplecalculator.p`
